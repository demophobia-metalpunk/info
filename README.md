# Demophobia · Press Kit

Página de press kit da Demophobia e do álbum *Perversidade e Violência* (2024).

Para publicar pelo GitHub Pages, entre em **Settings → Pages**, escolha **Deploy from a branch**, selecione a branch e a pasta `/ (root)` e salve.

- `index.html`: a página
- `assets/img/`: imagens otimizadas para a web
- `assets/press/`: arquivos em alta resolução para download da imprensa
